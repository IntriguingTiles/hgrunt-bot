RGrunt Privacy Policy

Here's how RGrunt uses your data outside of Discord:

  • If the level system is enabled, User IDs and associated XP are saved to a database in order to keep track of their current XP and level.
  • If the jail system is used, User IDs of jailed users are saved to a database in order to re-add the jail role if a jailed user leaves and rejoins the server. It is removed when a user is unjailed.
  • If the warn system is used, the User ID of the warned user and the User ID of the user that issued the warn are saved to a database in order to allow viewing warn history for a specific user.

This data is retained for as long as the bot remains in the server.

When RGrunt is removed from a server, all associated data and settings are permanently deleted.

Server staff may optionally configure RGrunt to log various events to a channel within their respective server. This may include the following user data, depending on how logging is configured:

  • The contents and attachments of messages that you have edited.
  • The contents and attachments of messages that have been deleted, either by you or by someone with the Manage Messages permission.
  • Your username and user ID at the time your message was edited or deleted.
  • Your username and user ID at the time you joined the server.
  • Your username and user ID at the time you left the server.
  • Your username and user ID at the time your roles were updated.
  • Your username and user ID at the time you were kicked from the server.
  • Your username and user ID at the time you were banned from the server.
  • Your username, old nickname (if applicable), new nickname (if applicable), and user ID at the time your nickname was updated.
  • If you perform moderation actions (such as kicking, banning, deleting messages, etc.), your username and user ID may appear in relevant logs.
  • If you modify the server (such as changing the server name, modifying channels, modifying roles, etc.), your username and user ID may appear in relevant logs.

As these logs go to a channel that the server staff control, it is up to the staff what they do with these logs, such as how long they last for, or if logs pertaining to you can be deleted. RGrunt has no control over this.

No additional user data is collected or stored.
